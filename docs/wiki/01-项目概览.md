# 01 项目概览

- **产品名**：Flowix（官网 <https://flowix-memo.com/>）
- **仓库**：<https://github.com/text2future/flowix>，MIT 协议开源
- **版本**：1.5.6（`package.json` / `app/Cargo.toml` / `app/flowix-desktop/tauri.conf.json` 三处强一致）
- **支持平台**：macOS 14+、Windows 10+（CI 另构建 Linux AppImage）

## 1. 项目定位

Flowix 是"给人和给 Agent 用的本地优先 Markdown 笔记本"：

1. **写**：纯 Markdown 文件落盘（默认笔记本在 `~/Documents/flowix`），任何编辑器都能打开；
2. **交**：在文档内调用 Agent（内置 DSH/Pi，或外部 Codex、Claude Code、OpenCode、Hermes 等 MCP/CLI 工具），只共享你选择的上下文；
3. **存**：Agent 产出的结果写回同一篇笔记，可审阅、编辑、复用；
4. **通**：`flowix-cli` 与 `flowix mcp`（MCP Server）让任意外部 Agent 通过 `mcp__flowix__memo` 工具读写本地笔记；
5. **选配云同步**：Flowix Cloud（v2 同步协议）提供账号、会员与多设备同步，Access Token 只驻内存。

核心产品能力：多笔记本管理、标签/颜色/属性体系、多维表格与媒体库（集合 schema v2）、版本历史（`.flowix/archives`）、全文搜索（SQLite FTS5 trigram）、声明式插件（思维导图/网页卡片）、Agent 会话管理、自动更新（App 与 DSH 双通道）。

## 2. 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面壳 | Tauri v2（Rust，静态窗口 + 运行时窗口，深链 `flowix://`，文件关联 `.md`） |
| 前端 | React 19 + TypeScript 5.8（strict）+ Vite 7 + Tailwind CSS 3.4 + shadcn/ui 变量 |
| 前端状态/编辑器 | Zustand 5（persist）、TipTap 3（Markdown 富文本）、CodeMirror 6 + Shiki 4、KaTeX、Mermaid 11、markmap |
| Rust 核心 | Cargo workspace（6 crates）、rusqlite（bundled SQLite）、serde、tokio、reqwest、notify、diffy、fs2、clap 4 |
| Agent 运行时 | Node.js 24（DSH 自包含运行时）、Cordis 插件体系、JSON-RPC 2.0（stdio JSONL / HTTP+SSE） |
| 工具链 | npm 10.8.2（钉版）、Vitest 4、cargo test/clippy、lefthook（占位未激活）、GitHub Actions |

```
flowix/

│   ├── flowix-installer-helper/#   Windows 安装/更新预检助手（NSIS 配套）

├── dsh/                        # 仅 upstream.lock.json（锁定上游 deepseek-harness commit）
├── scripts/                    # 构建/发布/校验脚本（.mjs，30+ 个）
├── docs/                       # 专题设计文档 + 本 wiki
├── examples/plain-report/      # 声明式插件示例（plugin.json + SKILL.md）
├── .flowix/templates/          # 72 个笔记本场景模板（编译期内嵌进桌面端）

├── vite.config.ts / tsconfig.json / tailwind.config.js / vitest.config.ts   # 前端构建根配置
└── package.json                # npm 根（版本、scripts、依赖）
```

## 4. 核心概念速查

| 概念 | 定义 | 关键位置 |
| --- | --- | --- |
| 笔记本（Notebook） | 一个本地文件夹 + `.flowix/` 元数据目录；注册在设备级 `~/.flowix/index.db` | `app/flowix-core/src/memo_file/notebook_registry.rs` |
| Note（笔记） | 笔记本内一个 `.md` 文件；身份 = `(notebook_id, relative_path)` | `app/flowix-core/src/memo_file/note_index.rs` |
| Memo（旧） | 带 Memo ID 的遗留身份模型，仅兼容读，不再为新写入生成 | `app/flowix-core/src/memo_file/index_store/` |
| 集合（Collection） | 多维表格 / 媒体库 / 文件夹表格，YAML 信封 `format: flowix.collection` schema v2 | `app/flowix-core/src/collection.rs`、`docs/COLLECTION-INDEX.md` |
| Agent 运行时 | 六种外部 CLI（Codex/Claude/Hermes/OpenCode/Pi/DSH）的子进程宿主抽象 | `app/flowix-desktop/src/agent_external/` |
| DSH | DeepSeek Harness：Flowix 托管下载的自包含 Node 24 运行时，内嵌 dsh-appserver | `app/flowix-desktop/src/dsh.rs`、`dsh-appserver/` |
| Thread / Turn / Item | Agent 会话协议模型（DSH Session → Thread；一次问答 → Turn；消息/工具 → Item） | `dsh-appserver/src/app-server/` |
| MCP | Model Context Protocol；`flowix mcp` 在 stdio 上暴露唯一 `memo` 工具 | `app/flowix-cli/src/mcp.rs` |
| 插件产物（Artifact） | 声明式插件（mindmap/webpage）生成的带 frontmatter 的文档 | `app/flowix-plugin-runtime/src/lib.rs` |
| v2 同步 | 协议 epoch 2：dirty→freeze→push→pull/bootstrap，last-commit-wins revision 链 | `app/flowix-sync/src/manager/v2_engine/` |

## 5. 用户数据布局（运行时）

```
~/.flowix/                          # 设备级数据（FLOWIX_HOME 可覆盖）
├── index.db                        # 笔记本注册表 + app_state（selected_notebook_id 等）
├── default.db                      # 凭据库 secret_kv（secure_delete=ON, 0600）
├── .memo-write.lock                # 旧版跨进程写闸门
├── locks/                          # files/<sha256>.lock / notebooks/<id>.lock / maintenance/
├── plugin/                         # <id>/plugin.json + SKILL.md；state.json 记录启停
├── templates/notebook-templates/   # 内置场景模板种子化副本
└── boot/                           # boot.json（device_id/onboarding）、security-bookmarks.json

<notebook>/                         # 笔记本目录（默认 ~/Documents/flowix）
├── **/*.md                         # 笔记正文（唯一内容真源，可带 YAML frontmatter）
├── .flowix/
│   ├── notebook.db                 # 笔记本 SQLite：notes 投影 + FTS5 + 旧 memo 表 + 集合/媒体
│   ├── notebook.json               # 笔记本身份 manifest
│   ├── archives/<id>/manifest.json # 版本历史（自动版间隔 1h，上限 20）
│   └── view-preferences.json       # 视图偏好
├── attachments/                    # 附件（参与云同步 blob 收集）
├── Mindmaps/                       # mindmap 插件产物
└── Plugins/<id>/                   # 其他插件产物
```
